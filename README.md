# Minswap Cardano DeFi Onboarding — Incentive Program

## About

A proof-of-concept incentive program to onboard users to Cardano DeFi via Minswap. The project designs and implements a points-based rewards system to grow DEX volume, TVL and daily active addresses by incentivizing trading, liquidity provision and cross-chain bridging.

## Goals

- Increase Minswap and Cardano DeFi usage metrics (DEX volume, TVL, DAU).
- Validate points-based incentive mechanics adapted for Cardano.
- Produce open-source tooling and documentation for future, larger campaigns.

## Core components

- Points System — awards points for activity across:
  - Trading volume and number of swaps
  - Liquidity provision (amount and duration)
  - Bridging in assets from other chains
- Abuse prevention — anti-bot and manipulation rules baked into the ruleset and indexer logic
- Dashboard — real-time rankings and points visibility; rewards distributed per milestone rules
